# Function Pointers

This directory contains ALU low-level programming exercises on function pointers in C.

## Requirements

- Compile with: `gcc -Wall -Werror -Wextra -pedantic -std=gnu89`
- Follow Betty style
- No global variables

## Files

- `0-print_name.c`: prints a name using a function pointer callback
- `1-array_iterator.c`: executes a function on each element of an array
- `2-int_index.c`: searches for an integer using a comparison callback
- `3-calc.h`, `3-get_op_func.c`, `3-main.c`, `3-op_functions.c`: simple calculator project
- `function_pointers.h`: function prototypes and includes
