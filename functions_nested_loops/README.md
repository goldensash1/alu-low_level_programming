# Functions, Nested Loops

This directory contains ALU low-level programming exercises focused on:
- Writing basic C functions
- Using nested loops
- Working with custom headers and prototypes
- Building with strict compiler flags

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`
- Compilation:

```bash
gcc -Wall -Werror -Wextra -pedantic -std=gnu89 <files>.c -o <output>
```

## Task 0

File: `0-putchar.c`

Program prints `_putchar` followed by a new line using the `_putchar` helper.

Example output:

```text
_putchar
```

## Files

- `main.h`: function prototypes for tasks in this project
- `_putchar.c`: helper for writing one character to standard output
- `*-main.c`: local test files (not required by checker output)

## Notes

- Keep generated binaries/object files out of version control.
- Ensure all source files end with a new line.
